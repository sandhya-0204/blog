# Sprinix Product Label

Sprinix Blog Extension for Magento2.


Description
-----------
The Magento 2 Blog Extension enables store owners to create and manage blogs within
their Magento store. This extension provides functionalities to create, edit, delete, and
organize blogs, categories, and tags. It also allows users to comment on blog posts and
reply to comments, enhancing user engagement.

Compatibility
-------------

- Magento Version =  2.4.3, 2.4.4, 2.4.5, 2.4.6, 2.4.7, 2.4.8                                                                                                                                                                                                                              


Installation Instructions
-------------------------

#####. Copy and paste

- Download `Blogs.zip` file . 
- Extract `Blogs.zip` file to `app/code/Sprinix/Blogs` ; You should create a folder path `app/code/Sprinix/ProductLabel` if not exist.
- Go to Magento root folder and run upgrade command line to install `Sprinix_Blogs`:

```
php bin/magento setup:upgrade
php bin/magento setup:di:compile
